漏洞串联
========================================

WEB前端与逻辑类串联
---------------------------------------
+ self-xss(无危/低危) + CSRF(中危) = 存储型XSS(高危)
+ 开放重定位(低危) + 钓鱼/CSRF(中危) = 可信域名钓鱼或绕过白名单(高危)
+ IDOR水平越权(中危) + 敏感功能点(中危) = 垂直越权/全量数据泄露(高危)

信息泄露与认证绕过类串联
---------------------------------------
+ 源码/环境变量泄露(低危) + 硬编码密钥/JWT Secret(低危) = 未授权访问管理后台(高危)
+ 信息泄露(低危) + 弱口令/默认口令(中危) + 后台高危功能(中危) = RCE(高危)
+ CRLF注入(低危) + 认证逻辑缺陷(中危) = 认证绕过/会话劫持(高危)

服务端请求与内网突破类串联
---------------------------------------
+ SSRF(中危) + 内网未授权服务(Redis/Memcached/Metadata低危) = 内网RCE/云环境接管(严重)
+ LFI本地文件包含(中危) + 日志投毒/调试信息泄露(低危) = RCE(严重)
